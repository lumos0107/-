# 02. 데이터베이스 테이블
> gildongmu DB — 11개 테이블 (이미 생성 완료)

---

## 테이블 관계도

```
jeju_road_points  (경로 탐색 전용, 독립 테이블)

users
  └─ courses (1:N)
  │    ├─ course_points (1:N)
  │    │    └─ course_segments (start_point_id, end_point_id 참조)
  │    │         └─ segment_obstacles (N:M ↔ obstacles)
  │    └─ course_places (N:M ↔ places)
  └─ running_records (1:N)
       └─ running_tracks (1:N)
```

---

## 용어 기준

| 기준 | 형식 |
|------|------|
| 컬럼명 | snake_case |
| 거리 | _meters |
| 경사도 | _percent |
| 시간(초) | _seconds |
| 타임스탬프 | _at |

## 00. jeju_road_points

제주도 전체 도로망 점 저장 (경로 탐색 전용).
배포 전 1회 수집 완료. 사용자 요청 시 공간 인덱스로 조회만 함.

```sql
CREATE TABLE jeju_road_points (
    point_id         INT PRIMARY KEY AUTO_INCREMENT,
    latitude         DECIMAL(9,6) NOT NULL,
    longitude        DECIMAL(9,6) NOT NULL,
    elevation_meters DECIMAL(6,2),           -- Google Elevation API 수집값
    road_type        VARCHAR(50),             -- OSM highway 태그값
    location         POINT GENERATED ALWAYS AS
                       (ST_SRID(POINT(longitude, latitude), 4326)) STORED NOT NULL,
    SPATIAL INDEX idx_jeju_road_location (location)
);
```

| 컬럼 | 역할 |
|------|------|
| elevation_meters | slope_penalty 계산에 사용 |
| road_type | footway / residential / path 등 |
| location | 반경 50m 공간 인덱스 조회용 |

**반경 조회 쿼리**
```sql
SELECT * FROM jeju_road_points
WHERE ST_Distance_Sphere(
    location,
    ST_SRID(POINT(126.531200, 33.499600), 4326)
) <= 50;
```

## 01. users

```sql
CREATE TABLE users (
    user_id                 INT PRIMARY KEY AUTO_INCREMENT,
    email                   VARCHAR(100) UNIQUE NOT NULL,
    password_hash           VARCHAR(255) NOT NULL,   -- bcrypt 해시값
    base_pace_seconds       INT,                     -- 평지 1km 페이스(초)
    slope_resistance_factor FLOAT DEFAULT 1.0,       -- 경사 저항 계수
    preferred_distance_meters INT,
    created_at              TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 02. courses

추천된 루프 코스 1개 단위 요약.

```sql
CREATE TABLE courses (
    course_id                INT PRIMARY KEY AUTO_INCREMENT,
    user_id                  INT,
    course_name              VARCHAR(200) NOT NULL,
    start_latitude           DECIMAL(9,6) NOT NULL,
    start_longitude          DECIMAL(9,6) NOT NULL,
    target_distance_meters   INT NOT NULL,    -- 사용자가 원한 거리
    total_distance_meters    INT NOT NULL,    -- 실제 생성된 거리
    average_slope_percent    FLOAT,
    obstacle_count           INT DEFAULT 0,
    estimated_duration_seconds INT,
    duplicated_ratio         FLOAT DEFAULT 0, -- 중복 구간 비율
    is_loop                  BOOLEAN DEFAULT TRUE,
    created_at               TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);
```

## 03. course_points

생성된 추천 경로의 좌표 점.

```sql
CREATE TABLE course_points (
    point_id                   INT PRIMARY KEY AUTO_INCREMENT,
    course_id                  INT NOT NULL,
    sequence_order             INT NOT NULL,       -- 1부터 시작
    latitude                   DECIMAL(9,6) NOT NULL,
    longitude                  DECIMAL(9,6) NOT NULL,
    elevation_meters           DECIMAL(6,2),       -- jeju_road_points에서 복사
    cumulative_distance_meters DECIMAL(8,2),       -- 출발점부터 누적 거리
    location                   POINT GENERATED ALWAYS AS
                                 (ST_SRID(POINT(longitude, latitude), 4326)) STORED NOT NULL,
    UNIQUE (course_id, sequence_order),
    SPATIAL INDEX idx_course_points_location (location),
    FOREIGN KEY (course_id) REFERENCES courses(course_id) ON DELETE CASCADE
);
```

> jeju_road_points는 탐색용 전체 도로망, course_points는 실제 추천된 경로의 점만 저장.
> location 인덱스는 reuse_penalty 반경 15m 조회에 사용.

## 04. course_segments

점과 점 사이 구간 저장. Score 계산 결과를 raw값으로 저장.

```sql
CREATE TABLE course_segments (
    segment_id            INT PRIMARY KEY AUTO_INCREMENT,
    course_id             INT NOT NULL,
    start_point_id        INT NOT NULL,
    end_point_id          INT NOT NULL,
    segment_order         INT NOT NULL,
    distance_meters       DECIMAL(6,2) NOT NULL,  -- haversine 계산 결과
    slope_percent         DECIMAL(5,2),            -- raw값 저장
    obstacle_penalty      INT DEFAULT 0,           -- raw값 저장
    reuse_penalty         INT DEFAULT 0,           -- raw값 저장
    facility_bonus        FLOAT DEFAULT 0,
    estimated_energy_kcal DECIMAL(6,2),
    UNIQUE (course_id, segment_order),
    FOREIGN KEY (course_id) REFERENCES courses(course_id) ON DELETE CASCADE,
    FOREIGN KEY (start_point_id) REFERENCES course_points(point_id) ON DELETE CASCADE,
    FOREIGN KEY (end_point_id) REFERENCES course_points(point_id) ON DELETE CASCADE
);
```

> 정규화는 DB에 저장하지 않고 알고리즘 내에서 처리.
```
slope_penalty_norm    = min(1.0, |slope_percent| / 20)
obstacle_penalty_norm = min(1.0, obstacle_penalty / 200)
reuse_penalty_norm    = min(1.0, reuse_penalty / 200)
```

## 05. obstacles

OSM 신호등/횡단보도 원본. 배포 전 1회 수집 완료.

```sql
CREATE TABLE obstacles (
    obstacle_id            INT PRIMARY KEY AUTO_INCREMENT,
    obstacle_type          VARCHAR(50) NOT NULL,   -- traffic_signal | crosswalk
    source                 VARCHAR(30) DEFAULT 'OSM',
    latitude               DECIMAL(9,6) NOT NULL,
    longitude              DECIMAL(9,6) NOT NULL,
    default_penalty_weight INT DEFAULT 0,
    location               POINT GENERATED ALWAYS AS
                             (ST_SRID(POINT(longitude, latitude), 4326)) STORED NOT NULL,
    SPATIAL INDEX idx_obstacles_location (location)
);
```

| obstacle_type | 기본 패널티 |
|---------------|------------|
| traffic_signal | 50 |
| crosswalk | 20 |

**반경 조회 쿼리**
```sql
SELECT * FROM obstacles
WHERE ST_Distance_Sphere(
    location,
    ST_SRID(POINT(126.531200, 33.499600), 4326)
) <= 100;
```

## 06. segment_obstacles

어떤 구간에 어떤 장애물이 반영됐는지 매핑.

```sql
CREATE TABLE segment_obstacles (
    mapping_id                 INT PRIMARY KEY AUTO_INCREMENT,
    segment_id                 INT NOT NULL,
    obstacle_id                INT NOT NULL,
    distance_to_segment_meters DECIMAL(5,2),  -- 장애물↔구간 거리
    applied_penalty_weight     INT DEFAULT 0, -- 실제 적용 패널티
    FOREIGN KEY (segment_id) REFERENCES course_segments(segment_id) ON DELETE CASCADE,
    FOREIGN KEY (obstacle_id) REFERENCES obstacles(obstacle_id) ON DELETE CASCADE
);
```

## 07. places

Google Places 편의시설 원본. 배포 전 수집 완료.

```sql
CREATE TABLE places (
    place_id        VARCHAR(255) PRIMARY KEY,  -- Google place_id
    name            VARCHAR(200) NOT NULL,
    category        VARCHAR(50) NOT NULL,       -- convenience_store | toilet | park
    latitude        DECIMAL(9,6) NOT NULL,
    longitude       DECIMAL(9,6) NOT NULL,
    open_now        BOOLEAN,
    address         VARCHAR(255),
    last_updated_at TIMESTAMP,
    location        POINT GENERATED ALWAYS AS
                      (ST_SRID(POINT(longitude, latitude), 4326)) STORED NOT NULL,
    SPATIAL INDEX idx_places_location (location)
);
```

**반경 조회 쿼리**
```sql
SELECT * FROM places
WHERE ST_Distance_Sphere(
    location,
    ST_SRID(POINT(126.531200, 33.499600), 4326)
) <= 500;
```

## 08. course_places

코스 주변 편의시설 매핑.

```sql
CREATE TABLE course_places (
    mapping_id                INT PRIMARY KEY AUTO_INCREMENT,
    course_id                 INT NOT NULL,
    place_id                  VARCHAR(255) NOT NULL,
    nearest_point_id          INT,
    distance_to_course_meters DECIMAL(6,2),
    facility_bonus            FLOAT DEFAULT 0,
    FOREIGN KEY (course_id) REFERENCES courses(course_id) ON DELETE CASCADE,
    FOREIGN KEY (place_id) REFERENCES places(place_id) ON DELETE CASCADE,
    FOREIGN KEY (nearest_point_id) REFERENCES course_points(point_id)
);
```

## 09. running_records

러닝 기록 요약.

```sql
CREATE TABLE running_records (
    record_id             INT PRIMARY KEY AUTO_INCREMENT,
    user_id               INT NOT NULL,
    course_id             INT,                    -- NULL 허용 (자유 러닝)
    total_distance_meters INT NOT NULL,
    total_time_seconds    INT NOT NULL,
    average_pace_seconds  INT NOT NULL,           -- 1km당 평균 페이스(초)
    started_at            TIMESTAMP NOT NULL,
    ended_at              TIMESTAMP NOT NULL,
    created_at            TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE,
    FOREIGN KEY (course_id) REFERENCES courses(course_id) ON DELETE SET NULL
);
```

> course_id ON DELETE SET NULL: 코스가 삭제돼도 러닝 기록은 유지됨.

## 10. running_tracks

실시간 GPS 이동 경로. running_records와 1:N.

```sql
CREATE TABLE running_tracks (
    track_id       INT PRIMARY KEY AUTO_INCREMENT,
    record_id      INT NOT NULL,
    sequence_order INT NOT NULL,
    latitude       DECIMAL(9,6) NOT NULL,
    longitude      DECIMAL(9,6) NOT NULL,
    recorded_at    TIMESTAMP NOT NULL,
    UNIQUE (record_id, sequence_order),
    FOREIGN KEY (record_id) REFERENCES running_records(record_id) ON DELETE CASCADE
);
```

> course_points: 추천 경로 (미리 계산)
> running_tracks: 실제 뛴 경로 (GPS 실시간 기록)
> 구조는 비슷하지만 역할이 다름.
